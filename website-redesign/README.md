## Key Design Decisions

- **Dual-audience split** — Homepage hero separates Reconstructive and Cosmetic pathways from the first interaction
- **WordPress CMS** — Selected for SEO control, HIPAA-plugin support, and long-term scalability (see `CMS Platform Comparison Proposal.xlsx` in `/strategy`)
- **HIPAA-compliant forms** — Jotform integration planned for consultation requests and patient intake
- **Analytics foundation** — Google Analytics 4 + Google Tag Manager setup as part of launch checklist
